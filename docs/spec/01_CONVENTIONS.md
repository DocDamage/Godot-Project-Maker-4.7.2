## 2. Python rules

* Python **3.12**. Use type hints everywhere. Use `from __future__ import annotations` at the top of every module.
* Formatter and linter: `ruff` (line length 100). Configure it in `pyproject.toml`:

```toml
[project]
name = "rpggen"
version = "0.1.0"
requires-python = ">=3.12"
dependencies = [
  "Pillow>=10.3",
  "numpy>=1.26",
  "jsonschema>=4.21",
  "py7zr>=0.21",
  "PySide6>=6.7",
]
[project.optional-dependencies]
dev = ["pytest>=8", "ruff>=0.5", "pyinstaller>=6.6"]
[project.scripts]
rpggen = "rpggen.cli:main"
[tool.ruff]
line-length = 100
[tool.ruff.lint]
select = ["E", "F", "I", "B", "UP", "SIM"]
[tool.pytest.ini_options]
markers = ["integration: needs RPGGEN_GODOT", "slow: long-running"]
```

* Use **dataclasses** (`@dataclass(frozen=True, slots=True)` where possible) for in-memory records. Convert to and from JSON dicts only in `catalog.py`, `config.py`, `ledger.py` and `inventory.py`, through `to_json()` and `from_json()` methods.
* Use **pathlib.Path** for every path. Never build paths by concatenating strings.
* Paths stored in JSON are **POSIX-style and relative** (`assets/packs/forest/Tiles/grass.png`). Convert with `paths.to_posix_rel(path, root)` and `paths.from_posix_rel(s, root)`.
* The GUI must never import from `rpggen.core.orchestrator` internals. It only calls `orchestrator.run(config, callbacks)` and the public functions of `catalog`, `config` and `adapters`.
* No module-level side effects other than constants and logger creation.

### 2.1 Deterministic JSON (`rpggen/jsonio.py`)

```python
def dumps(obj: Any) -> str:
    """json.dumps(obj, sort_keys=True, indent=2, ensure_ascii=False, separators=(",", ": "))
    + "\n". Floats are rounded to 6 decimal places before dumping (walk the structure).
    Tuples become lists. Raises TypeError for sets (sort them first)."""

def write(path: Path, obj: Any) -> None:
    """Atomic: write to path.with_suffix(path.suffix + ".tmp") with encoding utf-8 and
    newline="\n", fsync, then os.replace onto path."""

def read(path: Path) -> Any:
    """json.loads of utf-8 text. Raises RpgGenError(CAT-001) with the path on parse failure."""
```

Every JSON file the program writes goes through `jsonio.write`, with no exceptions.

### 2.2 Logging

* `logging_setup.configure(log_dir: Path, verbose: bool)` creates a file handler at `log_dir/rpggen.log` (DEBUG) and a console handler (INFO, or DEBUG when verbose).
* Each module uses `log = logging.getLogger(__name__)`.
* The log format is `%(asctime)s %(levelname)-7s %(name)s: %(message)s`.
* GUI progress is **not** logging. Progress goes through the callbacks object (T1.10).

### 2.3 Errors

* `rpggen/errors.py` defines:

```python
class Severity(StrEnum): ERROR = "error"; WARNING = "warning"; INFO = "info"

@dataclass(frozen=True, slots=True)
class Issue:
    code: str            # e.g. "ASSET-001"
    severity: Severity
    message: str         # what is wrong, one sentence
    fix: str             # recommended fix, one sentence
    file: str | None = None   # posix relative path when relevant
    detail: dict[str, Any] = field(default_factory=dict)

class RpgGenError(Exception):
    def __init__(self, code: str, message: str, *, file: str | None = None, **detail): ...
    # .issue property returns Issue(code, ERROR, message, CODES[code].fix, file, detail)

CODES: dict[str, CodeInfo]   # loaded from 03_ERROR_CODES table, see T1.03
```

* Fatal problems raise `RpgGenError`. Non-fatal problems are appended to an `IssueList` (a simple list wrapper with `add(code, message, file=None, **detail)`, which looks up severity and fix from `CODES`).
* Using an unknown code raises `KeyError` immediately. That keeps the code table complete.

## 3. GDScript rules

* Use static typing everywhere: `var speed: float = 80.0`, `func move(dir: Vector2) -> void:`.
* Use tabs for indentation, which is the Godot default.
* Files are `snake_case.gd`. Class names are `PascalCase`.
* **Runtime addon classes use `class_name` with the prefix `Rpg`**, e.g. `RpgStats` or `RpgInventory`. The prefix avoids collisions with user classes.
* **Builder scripts do not use `class_name` at all.** They load each other with `preload("res://generated/builder/lib/json_util.gd")`, because global class registration may not be ready during headless `--script` runs. ⚠ VERIFY in T1.07 whether `class_name` resolves under `--script` after `--import`. Even if it does, keep the preload rule.
* Signals are past tense (`died`, `item_added`). Methods are verbs.
* Never use `get_node("../..")` paths across scene boundaries. Use exported `NodePath` values set by recipes, groups, or the `Events` bus.
* Every runtime script that can fail logs through `push_error("[RPG-<AREA>] message")`. The validator searches the logs for the `[RPG-` prefix.
* Avoid `await` inside the builder. The builder is synchronous, apart from the import step, which runs in a separate process.

## 4. IDs and slugs (`rpggen/ids.py`)

```python
def slug(text: str) -> str:
    """Lowercase. Unicode NFKD, then strip combining marks. Replace any run of chars not in
    [a-z0-9] with "_". Strip leading/trailing "_". If empty, return "x".
    If it starts with a digit, prefix "n". Examples:
      "Hero 01.png" -> "hero_01_png" (callers strip extension first)
      "Árbol-Grande" -> "arbol_grande"
      "123" -> "n123" """

def asset_id(pack_id: str, rel_path_in_pack: str) -> str:
    """pack_id + "." + ".".join(slug(part) for part in path_without_extension.split("/"))
    e.g. ("forest_pack", "Tilesets/Grass Tiles.png") -> "forest_pack.tilesets.grass_tiles" """

def disambiguate(ids_in_order: list[str]) -> list[str]:
    """Given ids in sorted-source-path order, keep the first occurrence as-is and suffix later
    duplicates with "__2", "__3", ... Deterministic because input order is sorted."""

def pack_id_from_name(name: str, existing: set[str]) -> str:
    """slug(stem of archive or folder name), shortened to 40 chars, then disambiguated against
    existing with "_2", "_3"."""
```

Object IDs (regions cut from sheets) are `<sheet_asset_id>#<object_slug>`.
Animation set IDs are `<asset_id>@anim`.
Entity IDs in maps are `<map_id>_<kind>_<nnn>`, with a 3-digit zero-padded counter.

## 5. Sorting rule (determinism)

Wherever a list is built from the filesystem, a dictionary or a set, sort it with
`key=lambda p: (p.casefold(), p)` on the POSIX relative path or ID string before using it. Write a unit test for every function that returns such a list.

## 6. How Godot content gets created (critical)

| Content | How it is made | Who writes the file |
|---------|----------------|---------------------|
| Runtime `.gd` scripts | Hand-written in `godot_templates/addons/rpg_runtime/` | Copied by Python |
| Editor plugin `.gd` | Hand-written in `godot_templates/addons/rpg_project_tools/` | Copied by Python |
| `plugin.cfg` | Hand-written (simple INI; format in T8.01) | Copied by Python |
| `.gd.uid` files | Created by Godot when the template project is opened/imported in CI | Committed; copied by Python |
| Every `.tscn` | Built by a GDScript **recipe** function, saved with `ResourceSaver.save` | Godot builder |
| Every `.tres` (TileSet, SpriteFrames, Theme, items…) | Built by a recipe | Godot builder |
| `project.godot` settings | Set by `builder/recipes/project_settings_recipe.gd` via `ProjectSettings.set_setting` + `ProjectSettings.save()` | Godot builder |
| Starter `project.godot` (before Godot first runs) | Minimal text written by Python (T1.06 defines the exact text) | Python |
| JSON (catalog, config, ledger, results) | Python `jsonio` / GDScript `json_util.gd` | Either |

### 6.1 Recipe contract

Every recipe is a GDScript file under `builder/recipes/` that extends `RefCounted` and has:

```gdscript
## Returns the list of res:// paths this recipe will write, given the inputs.
func outputs(ctx) -> PackedStringArray

## Returns a stable string hash of everything that affects the output (catalog slice,
## config slice, recipe version constant). Used to skip unchanged outputs.
func input_hash(ctx) -> String

## Builds and saves. Returns an Array of issue dictionaries
## {code, severity, message, file}.
func build(ctx) -> Array
```

* `ctx` is a `BuildContext` object (`builder/lib/build_context.gd`) holding the parsed catalog, the parsed config, a results collector and helper functions.
* Each recipe has `const RECIPE_VERSION := 1`. Increase it whenever the recipe's output changes, so the input hash changes.
* **Skip rule:** the builder keeps `rpggen/build_state.json` (`02_SCHEMAS.md` §8), mapping each output path to the input hash used last time. If the hash is unchanged and the file exists, the recipe is skipped. This guarantees zero git diff on no-op regeneration.

### 6.2 Building a scene in code (pattern every scene recipe follows)

```gdscript
func _save_scene(root: Node, path: String) -> int:
	_set_owner_recursive(root, root)
	var packed := PackedScene.new()
	var err := packed.pack(root)
	if err != OK:
		return err
	DirAccess.make_dir_recursive_absolute(path.get_base_dir())
	err = ResourceSaver.save(packed, path)
	root.free()
	return err

func _set_owner_recursive(node: Node, owner: Node) -> void:
	for child in node.get_children():
		child.owner = owner
		# Do NOT descend into instanced sub-scenes: their children belong to them.
		if child.scene_file_path == "":
			_set_owner_recursive(child, owner)
```

* Children without `owner` set are **not saved**. This is the most common bug, so test for it (T1.07).
* To add an instance of another scene as a child: `var inst := load(path).instantiate(); parent.add_child(inst); inst.owner = root`. Do not recurse into `inst`.
* Scripts are attached with `node.set_script(load("res://addons/rpg_runtime/...gd"))` **before** setting script properties.
* Exported properties are set with `node.set("prop_name", value)` after attaching the script, so values are saved into the scene.

## 8. Godot invocation (Python side, `rpggen/core/godot.py`)

All calls go through one function:

```python
@dataclass(frozen=True, slots=True)
class GodotRun:
    returncode: int
    stdout: str
    stderr: str
    log_path: Path
    timed_out: bool

def run_godot(exe: Path, project: Path, args: list[str], *, timeout_s: int,
              log_name: str, log_dir: Path) -> GodotRun:
    """Command: [exe, "--headless", "--path", str(project), *args]
    - Use subprocess.run with capture_output=True, text=True, encoding="utf-8",
      errors="replace", timeout=timeout_s.
    - Set env var "RPGGEN" = "1".
    - Write combined output to log_dir / f"godot_{log_name}.log".
    - On TimeoutExpired: kill the process tree (taskkill /T /F /PID on Windows) and
      return timed_out=True.
    - Never raises on non-zero returncode; callers decide."""
```

Use the **console** build of Godot on Windows (`*_console.exe`) when it sits next to the selected exe, because the GUI build does not attach stdout. `godot.find_console_exe(exe)` returns the console sibling if it exists, otherwise `exe`.

Timeouts: import 600 s, build 600 s, validate 300 s, smoke 300 s, version check 30 s.

## 9. Git and commits

* Use one commit per task card.
* Commit `test_packs/synthetic/` output. It is deterministic, and the tests compare against it.
* Never commit `.godot/` directories, the `godot_templates/.godot/` folder, or any commercial asset.
