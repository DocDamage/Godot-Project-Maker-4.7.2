# M6 — Shared RPG Systems (Runtime Addon)

**Goal:** `addons/rpg_runtime/` provides the full shared core: an events bus, game state, scene routing, saving, stats, items, inventory, dialogue, interaction, settings, audio, UI and translation-ready strings. A title → new game → talk to NPC → open chest → save → load loop works and is smoke-tested.

**Runtime addon layout (final):**
```text
addons/rpg_runtime/
├── plugin.cfg               (name="RPG Runtime", version="0.1.0"; it is not an editor plugin, but the cfg documents the version)
├── VERSION                  (single line, semver; the generator compares it on regeneration)
├── CHANGELOG.md
├── LICENSE                  (MIT-0)
├── core/      events.gd, game_state.gd, save_manager.gd, settings.gd, boot.gd, rng.gd, util.gd
├── world/     scene_router.gd, map_root.gd, door.gd, spawn_point.gd, world_object.gd, persistent.gd, chest.gd, sign.gd
├── actors/    actor.gd, components/*.gd, player_input.gd, npc.gd, animation_driver.gd
├── data/      stats.gd, item_definition.gd, actor_definition.gd, enemy_definition.gd,
│              encounter_data.gd, encounter_result.gd, inventory.gd, loot_table.gd
├── dialogue/  dialogue_resource.gd, dialogue_line.gd, dialogue_choice.gd, dialogue_runner.gd, condition.gd
├── combat/    combat_mode.gd (abstract contract)            ← archetypes live in addons/rpg_runtime/archetypes/<name>/
├── ui/        scripts for UI scenes (scenes themselves are generated by recipes)
├── audio/     audio_service.gd
└── debug/     smoke_runner.gd, debug_overlay.gd
```

**Autoloads** (registered by the project-settings recipe, in this order): `Events`, `GameState`, `SaveManager`, `SceneRouter`, `RpgSettings`, `RpgSmoke`. No others.

**Rule:** gameplay scripts may call autoloads. Autoloads never reference scene nodes, except that SceneRouter holds the current map root.

## T6.06 — Dialogue

**Depends on:** T6.05
**Files:** `dialogue/*.gd`, `ui/dialogue_box.gd`, the recipe `ui_recipes.gd` (DialogueBox scene), tests

```gdscript
class_name RpgDialogueLine extends Resource
@export var id: StringName = &""            # optional label for jumps
@export var speaker: String = ""            # tr key or literal
@export var portrait: Texture2D
@export_multiline var text: String = ""     # tr key or literal
@export var choices: Array[RpgDialogueChoice] = []
@export var condition: String = ""          # line is skipped if condition is false
@export var events: PackedStringArray = []  # executed when the line is shown
@export var next: StringName = &""          # jump target (empty = next line)

class_name RpgDialogueChoice extends Resource
@export var text: String
@export var next: StringName                # line id
@export var condition: String = ""

class_name RpgDialogueResource extends Resource
@export var lines: Array[RpgDialogueLine] = []
```

**Condition mini-language** (`condition.gd`, a pure function `evaluate(expr: String) -> bool`):
* Grammar: `expr := term (("and"|"or") term)*`; `term := ["not"] atom`; evaluated left to right with **no precedence**. The docs say so, and conditions with mixed `and`/`or` are flagged with a warning by the content validator.
* Atoms:
  * `flag:<entity>.<key>` — true if the flag is truthy
  * `item:<id>[>=N]`
  * `gold>=N`
  * `level>=N`
  * `quest:<id>=<state>`
* Unknown atoms → false, plus `push_error("[RPG-DLG] unknown condition atom …")`.

**Events:** `set_flag:<entity>.<key>=<value>`, `give_item:<id>[:qty]`, `take_item:<id>[:qty]`, `give_gold:N`, `set_quest:<id>=<state>`, `heal_full`, `emit:<name>[:arg]` (→ `Events.dialogue_event`). Never `eval`. Parse each event with string splits.

**`RpgDialogueRunner`** (a RefCounted owned by the DialogueBox):
* `start(res)`, `current() -> RpgDialogueLine`, `advance()`, `choose(i)`, `is_finished()`.
* Skips lines whose condition is false.
* Executes events once when a line becomes current.
* An infinite-loop guard stops after 1,000 jumps without a displayed line.

**DialogueBox UI** (generated scene `generated/scenes/ui/dialogue_box.tscn`; script `ui/dialogue_box.gd`):
* A CanvasLayer (layer 50) with a bottom panel (9-slice from the UI theme), a portrait TextureRect, a speaker Label and a body `RichTextLabel` (BBCode off).
* Typewriter effect: `visible_ratio` tweened at `RpgSettings.text_speed` (characters per second); instant if text speed is "instant".
* Choices: a VBox of Buttons; focus goes to the first one.
* `confirm` while typing → completes the text. `confirm` when complete → advances.
* Player input is disabled while the box is open (`actor.input_enabled = false`). Emits `dialogue_started` and `dialogue_finished`.

**JSON import (editor convenience):** `dialogue/json_import.gd` with `static func from_json(text: String) -> RpgDialogueResource`, using the v1 plan's JSON shape (`speaker`, `text`, `choices[{text, next}]`, `condition`, `events`, `id`). It is exposed in the editor dock in M8.

**Recipe:** the starter NPC gets `game/data/dialogue/npc_greeting.tres` (user_seed) with 3 lines: a greeting, a choice ("Any tips?" / "Bye"), and a branch that sets the flag `starter_npc.talked=true` and gives 1 potion the first time only, using condition `not flag:starter_npc.talked`.

**Tests:** condition evaluation table; runner flow through a choice; events executed once; skipped lines.

## T6.09 — SaveManager

**Depends on:** T6.04
**Files:** `core/save_manager.gd`, `tests/unit/test_save_manager.gd`

```gdscript
extends Node
const SAVE_VERSION := 1
const DIR := "user://saves"
const SLOTS := 3
func save(slot: int) -> bool
func load(slot: int) -> bool
func has_save(slot: int) -> bool
func header(slot: int) -> Dictionary          # {} if none or corrupt
func delete(slot: int) -> void
func _migrate(d: Dictionary) -> Dictionary    # applies MIGRATIONS[v] for v in d.save_version .. SAVE_VERSION-1
var MIGRATIONS := {}                          # {0: Callable} — empty at v1; tests use a fake migration
```

Save algorithm (exactly):
1. `data := GameState.to_dict()`; add `save_version`, `header` and `world` (current map, position, facing).
2. `data.checksum = JSON.stringify(data_without_checksum, "", true).sha256_text()`.
3. `text := JSON.stringify(data, "  ", true)`.
4. Write `slot_N.tmp`: `FileAccess.open(…, WRITE)`, `store_string(text)`, `flush()`, `close()`.
5. Re-open `slot_N.tmp`, parse it and compare the checksum. If they differ → delete the tmp file and return false.
6. If `slot_N.json` exists → copy it to `slot_N.backup.json` with `DirAccess.copy_absolute` (overwrite).
7. Remove `slot_N.json` if it exists, then `DirAccess.rename_absolute(tmp, json)`.
8. Emit `game_saved`.

Load: try `slot_N.json`, verifying its checksum. On failure, try `slot_N.backup.json` and notify "Save was damaged; loaded backup." On failure again, return false. Then migrate if `save_version` is lower, refuse if it is higher (notify "Save from newer version"), call `GameState.from_dict`, call `SceneRouter.reload_from_state()`, and emit `game_loaded`.

**Tests:** round-trip; a corrupted main file falls back to the backup; a tampered checksum is rejected; a version-0 fake save migrates through a test migration; a save from a newer version is refused.

## T6.10 — Settings, input remapping, audio buses

**Depends on:** T6.01
**Files:** `core/settings.gd` (autoload `RpgSettings`), `audio/audio_service.gd`, `audio_bus_recipe.gd`

* Settings file: `user://settings.cfg` (`ConfigFile`). Sections:
  * `audio`: `master`, `music`, `sfx`, `ui`, each 0..1, default 0.8.
  * `video`: `fullscreen`, default false.
  * `text`: `speed` — "slow" 20 cps, "normal" 40, "fast" 80, "instant".
  * `access`: `ui_scale` 1.0/1.25/1.5.
  * `input`: an action → array of serialized events.
* Remapping: `rebind(action, old_event, new_event)` updates `InputMap` and saves the change.
  * Serialized key events are stored as `{"type":"key","physical":<int>}`, joy buttons as `{"type":"joy_button","index":i}`, and so on.
  * On load, user bindings **replace** the project defaults for that action.
* `audio_bus_recipe.gd` creates `default_bus_layout.tres` with the buses Master, Music, SFX and UI, each sending to Master. It sets the project setting `audio/buses/default_bus_layout`. ⚠ VERIFY the key.
* `RpgAudio` is a scene node, **not an autoload**. It is created by boot as a child of SceneRouter so it persists across scenes. It provides `play_music(asset_id or stream, fade 0.5 s)` with crossfade between two players, `play_sfx(stream)` with a pool of 8 players, and `play_ui(stream)`. Audio catalog assets are loaded by path from the catalog-derived index `res://rpggen/audio_index.json` (written by a recipe).
