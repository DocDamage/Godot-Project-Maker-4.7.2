# rpggen community profile registry

The community registry of pack profiles for [rpggen](https://github.com/DocDamage/Godot-Project-Maker-4.7.2).
It is a folder of the main repository: rpggen downloads it from
`raw.githubusercontent.com/DocDamage/Godot-Project-Maker-4.7.2/main/registry/`. There is no second
repository to maintain.

```text
profiles/<profile_id>.rpgprofile.json   one file per pack, CC0-1.0, data only
index.json                              generated by CI: [{profile_id, title, fingerprint_hashes, author, license}]
scripts/build_index.py                  validates every profile and regenerates index.json
scripts/profile.schema.json             copy of rpggen/schema/profile.schema.json
CONTRIBUTING.md                         how to add a profile
```

The workflow `.github/workflows/registry.yml` (repository root) runs the script when anything under
`registry/` changes, and regenerates `index.json` on `main`.

rpggen downloads `index.json` **only when the user clicks "Find profile online"**. It matches the
local pack's file hashes against each entry's `fingerprint_hashes` (at least 50% overlap),
downloads the chosen profile, validates it and installs it. See `rpggen/core/profile_registry.py`.

## Forks and test servers

Set `RPGGEN_REGISTRY_BASE` to an https URL ending in the folder that holds `index.json` to use
another registry. Keep `scripts/profile.schema.json` in step with the app's schema (a test compares
the two).
