# rpggen-profiles

The community registry of pack profiles for [rpggen](https://github.com/rpggen/rpggen).
This folder is the content of the separate `rpggen-profiles` repository; it lives in the rpggen
repository until that repository is created, and is kept here so that CI keeps the validator and
the client in agreement.

```text
profiles/<profile_id>.rpgprofile.json   one file per pack, CC0-1.0, data only
index.json                              generated by CI: [{profile_id, title, fingerprint_hashes, author, license}]
scripts/build_index.py                  validates every profile and regenerates index.json
scripts/profile.schema.json             copy of rpggen/schema/profile.schema.json
.github/workflows/validate.yml          runs the script on every push and pull request
CONTRIBUTING.md                         how to add a profile
```

rpggen downloads `index.json` from the raw URL **only when the user clicks "Find profile online"**.
It matches the local pack's file hashes against each entry's `fingerprint_hashes` (at least 50%
overlap), downloads the chosen profile, validates it and installs it. See
`rpggen/core/profile_registry.py`.

## Publishing the repository

1. Create the `rpggen-profiles` repository and copy this folder's contents to its root.
2. Run `python scripts/build_index.py` once and commit `index.json`.
3. If the repository lives under another owner or branch, change `REGISTRY_BASE` in
   `rpggen/core/profile_registry.py`.
4. Keep `scripts/profile.schema.json` in step with the app's schema (a test in the rpggen
   repository compares the two).
