# Claude Code memory of this project

A copy of Claude Code's auto-memory for this repository (made on 2026-10-25 so that work can
go on on another computer). `MEMORY.md` is the index; each other file is one memory.

To use it on another machine, copy these files (all but this README) into that machine's
memory folder for the project, `~/.claude/projects/<folder>/memory/`, where `<folder>` is the
project's path with `:`, `\` and `/` written as `-`
(here it is `C:\Users\Doc\.claude\projects\f--Godot-Project-Maker\memory\`), or point
Claude Code at this folder and ask it to read them.

Some of it is about this machine (the F: drive, `F:\rpggen_scratch`, where Godot and the
asset packs lie): check the paths on the other one.
